# Tribal Data Mapping Tool

This is the GitHub Repository for the [CA Water Boards Tribal Data Mapping Tool - User Manual]([url](https://cawaterboarddatacenter.github.io/tribal-data-mapping-manual/))

The Tribal Data Mapping Tool comprises:
- An [ESRI Map]([url](https://gispublic.waterboards.ca.gov/portal/home/item.html?id=a71c1841907240e1a4d896c8cf2302a8)), which includes curated data layers that have been requested by Tribal partners and that may be useful for California Native American Tribes (tribes) doing environmental or water related work.

- The [User Manual]([url](https://cawaterboarddatacenter.github.io/tribal-data-mapping-manual/)), which provides guidance and context so it’s easier for all audiences to use the Map. 

- A [Project Management Board]([url](https://github.com/orgs/CAWaterBoardDataCenter/projects/8/views/1)), which provides the status of ongoing Map and User Manual development efforts.
